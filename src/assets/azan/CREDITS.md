# Azan recordings

Source: the public GitHub collection https://github.com/Kiwifu/adhan-mp3 (no licence stated by the collection).
Files were trimmed and loudness-normalised (EBU R128, −16 LUFS) for consistent volume. The `-short` files contain the
opening *Allahu Akbar* only, with a fade-out.
